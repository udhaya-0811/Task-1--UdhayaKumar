# Random Number Guessing Game

## Description
A Java console game where the player guesses a randomly
generated number between 1 and 100.

## Features
- Random number generation
- Three rounds
- Five attempts per round
- Higher and lower hints
- Input validation
- Score tracking

## Technologies Used
- Java
- Scanner
- Random
- Loops
- Conditional Statements
- Exception Handling

## How to Run
1. Install the Java JDK.
2. Compile the program:
   javac NumberGame.java
3. Run the program:
   java NumberGame
